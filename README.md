# Sales Data Analysis Using Python

A beginner-friendly data analysis project using Python, pandas, and Matplotlib to analyze sales data and extract useful business insights.

## Project Overview

This project analyzes sales data for three products: Laptops, Phones, and Tablets.

The analysis includes data cleaning, sales calculations, product performance analysis, and data visualization.

## Tools & Technologies

* Python
* pandas
* Matplotlib
* Jupyter Notebook

## Key Analysis

* Calculated total sales
* Analyzed sales by product
* Compared product quantities
* Calculated sales percentages
* Checked for missing values
* Created visualizations to understand sales performance

## Key Insights

* Total sales: **$8,400**
* Phones generated the highest sales: **$4,500 (53.57%)**
* Laptops generated **$2,400 (28.57%)**
* Tablets generated **$1,500 (17.86%)**
* No missing values were found in the dataset
